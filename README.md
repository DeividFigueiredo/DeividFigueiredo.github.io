# 🎨 Portfólio - Deivid Figueiredo

Bem-vindo ao meu portfólio digital! Este é um site moderno e responsivo criado com HTML, CSS e JavaScript puro.

## 🚀 Acesso

Visite meu portfólio em: [DeividFigueiredo.github.io](https://DeividFigueiredo.github.io)

## 📋 Seções

- **Sobre Mim** - Conheça um pouco sobre meu perfil
- **Skills** - Tecnologias que domino
- **Projetos** - Meus principais projetos
- **Contato** - Links para entrar em contato comigo

## 💻 Tecnologias Utilizadas

- HTML5
- CSS3 (com Flexbox e Grid)
- JavaScript (Vanilla)
- Font Awesome Icons
- Responsivo (Mobile-first)

## 🛠️ Como Personalizar

### 1. Atualize suas informações
- Altere nome, descrição e bio no arquivo `index.html`

### 2. Adicione seus projetos
- Edite a seção de projetos com links para seus repositórios
- Atualize as tags de tecnologias

### 3. Atualize os links de contato
- LinkedIn
- GitHub
- Email

### 4. Customize cores
- Abra `style.css` e modifique as variáveis CSS em `:root`

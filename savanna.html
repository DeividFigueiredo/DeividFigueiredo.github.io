Savanna

Plataforma de base para desenvolvimento rápido de sistemas web com foco em gestão comercial, autenticação, multiempresa, dashboards e módulos de negócio reutilizáveis. O projeto foi estruturado para acelerar a criação de produtos com arquitetura escalável e padrões prontos para evolução.

Resumo

O Savanna reúne a base técnica de um sistema completo: API, autenticação JWT, usuários e papéis, organização por empresa, módulos de gestão e um conjunto de telas prontas para iniciar novos produtos com produtividade e consistência.

Stack

TypeScript, React 19, Vite, NestJS, Prisma, PostgreSQL, Docker, JWT, Swagger.

Resultados

Criação de uma base reutilizável para acelerar o desenvolvimento de sistemas web, reduzindo retrabalho e padronizando autenticação, estrutura e fluxo de produto.

Funcionalidades

Multiempresa, autenticação com refresh token, dashboard, usuários, perfil, cadastro e módulos de CRM como leads, pipelines e negociações como exemplo.
